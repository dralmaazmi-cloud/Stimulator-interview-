# مدرّب المقابلات القيادية

تطبيق ويب تقدّمي عربي (PWA) للمذاكرة والتدريب على المقابلات القيادية المبنية على الكفاءات. الإصدار الحالي `0.5.1-alpha-3` يضيف محاكاة المقابلة بالذكاء الاصطناعي إلى وظائف المرحلة الأولى المحلية، ويصلح كل بنود تقرير التدقيق المستقل (راجع `CHANGELOG_v0.5.1.md`).

## ما يعمل الآن

### التعلّم المحلي — يعمل دون إنترنت

- 6 وحدات مرتبة تعرض محتوى المرجع كاملًا بأسلوب واضح.
- 89 سؤالًا أساسيًا مميزًا مع المطلوب والنقاط والإجابة النموذجية، مع إبقاء 38 صياغة إضافية قابلة للعرض.
- 130 تمرين اختيار من متعدد بتفسيرات تعليمية من المرجع؛ يظهر ثلاثة فقط كحد أقصى في الجولة.
- صفحات للكفاءات الثماني وقيادة المهمة والذكاء الاصطناعي والتحضير النهائي.
- باني تقديم ذات محلي لنسختي 60 و120 ثانية وفق الماضي ثم الحاضر ثم المستقبل.
- بحث وحفظ أسئلة ونسخ احتياطي ومظهر فاتح وداكن وخط عربي محلي.

### المرحلة الثانية — تحتاج الإنترنت ومفتاحًا في الخادم

- محاكاة بسؤال واحد، أو محاكاة واقعية، أو ممتدة.
- إجابة نصية أو تسجيل صوتي حتى 120 ثانية، مع تنبيه عند 90 ثانية.
- ثلاث خطوات منفصلة للصوت: تفريغ حرفي، مراجعة المستخدم للنص، ثم التقييم.
- تقييم `STAR-L` و`SEAL` والأسئلة العامة وتقديم الذات.
- التحقق البرمجي من مخطط JSON ومن كل اقتباس قبل عرض الدرجة.
- حساب الدرجة في الخادم بأوزان ثابتة؛ النموذج لا يحسب الدرجة النهائية.
- صفر إلى سؤالي متابعة عند وجود نقص واضح فقط، تُعاد ضمن استجابة التقييم نفسها.
- حفظ والخروج ثم استئناف الجلسة من نفس السؤال ونفس المسودة.
- التقرير المحفوظ يعرض المعايير والاقتباسات كاملة ويُطبع كاملًا.
- مقارنة بنموذج الدليل بعد التقرير، من دون إرسال النموذج إلى محرك التقييم.
- تقارير سؤال وجلسة، مقارنة محلية بالجلسة السابقة، وطباعة أو حفظ PDF.
- تحسين لغوي اختياري لتقديم الذات مع وجوب اعتماد المستخدم للنص المقترح.
- حفظ التقارير محليًا وعدم حفظ الصوت أو تسجيل نص الإجابات في سجل الخادم.

المرحلة الثانية في حالة **Alpha-3 جاهزة للنشر التجريبي**. الاختبارات المحلية وأدوات التدقيق (`audit-harness/`) ناجحة، لكن اعتمادها النهائي (beta للمجموعة المغلقة) يحتاج مفتاح خدمة فعليًا، وتشغيل مجموعة المعايرة حيًا، واختبار التسجيل على iPhone.

## تشغيل محلي

واجهة المرحلة الأولى فقط لا تحتاج إلى تثبيت حزم:

```bash
python3 -m http.server 4173 --directory dist
```

ثم افتح `http://localhost:4173`. نقاط `/api` لن تعمل مع خادم الملفات البسيط؛ اختبرها عبر Vercel بعد إضافة متغير البيئة.

الأوامر المتاحة:

```bash
npm run derive
npm run fixtures
npm test
```

- `derive`: يعيد بناء الطبقة المشتقة دون تعديل المرجع، ثم يطبّق `tools/exercise-overrides.json` على التمارين.
- `exercise-overrides`: يعيد توليد ملف التجاوزات من المرجع ثم يطبّقه.
- `fixtures`: يعيد بناء مجموعة معايرة من 95 حالة (منها 5 حالات حقن).
- `test`: يشغّل بوابتي المرحلة الأولى والثانية بلا استهلاك API.
- `test:live`: يشغّل المعايرة على رابط منشور عند ضبط `PHASE2_BASE_URL`.

## النشر من iPhone عبر GitHub وVercel

1. ارفع محتويات مجلد المشروع إلى مستودع GitHub مع الحفاظ على المجلدات.
2. في Vercel اختر **Add New → Project** ثم اختر المستودع.
3. اجعل Framework Preset هو **Other**. ملف `vercel.json` يحدد `dist` كمجلد الإخراج.
4. قبل النشر افتح **Environment Variables** وأضف:
   - الاسم: `GEMINI_API_KEY`
   - القيمة: مفتاحك؛ لا تضعه في GitHub ولا في ملفات `dist`.
5. متغيرات اختيارية:
   - `GEMINI_MODEL` لتغيير نموذج التقييم والتفريغ.
   - `GEMINI_RETRY_MODEL` لنموذج إعادة المحاولة عند فشل المخطط أو الاقتباسات.
   - `RATE_LIMIT_EVALUATE` (للنشر التجريبي فقط) لرفع حد التقييم لكل (IP + معرّف عميل) من 40/ساعة، و`RATE_LIMIT_IP` لرفع حد العنوان من 200/ساعة أثناء تشغيل مجموعة المعايرة.
6. اضغط **Deploy**. عند إضافة المفتاح بعد أول نشر، نفّذ **Redeploy** كي يصل إلى الوظائف.
7. افتح `/api/health` على رابط التطبيق. يجب أن تظهر `"configured": true`.
8. اختبر إجابة نصية أولًا، ثم تسجيلًا صوتيًا على Safari، ثم من نسخة PWA المثبتة.
9. اختبر وضع الطيران: يجب أن يبقى التعلّم وبنك الأسئلة متاحين، بينما تظهر رسالة واضحة للمحاكاة.

لا ترسل المفتاح في المحادثة ولا تكتبه في الكود. يوضع في إعدادات Vercel فقط.

## الخصوصية

- الصوت يُرسل للتفريغ ثم تُصفّر ذاكرته في وظيفة الخادم بعد الرد. الخادم يتحقق من الترويسة الثنائية للملف قبل الإرسال.
- كل طلب إلى المزود يحمل `store: false`؛ لا يُخزَّن الطلب أو الاستجابة لدى المزود ولا تُستخدم محادثات محفوظة.
- المستخدم يراجع التفريغ ويصححه قبل إرسال النص للتقييم.
- سجل الخادم يحفظ نوع الطلب والمدة والرموز ونتيجة التحقق فقط؛ لا يحفظ الصوت أو نص الإجابة.
- الجلسات والتقارير ومسودة تقديم الذات محفوظة على جهاز المستخدم في IndexedDB.
- زر حذف البيانات المحلية موجود في الإعدادات.
- التطبيق أداة تدريب ولا يصدر نجاحًا أو رسوبًا ولا يتنبأ بنتيجة المقابلة.

## ما لم ينفذ بعد

هذه عناصر المرحلة الثالثة، وليست نقصًا في نطاق المرحلة الثانية:

- حصص خادمية يومية وأسبوعية ومخزن KV.
- سقف ميزانية شهري وإيقاف طارئ.
- رموز دخول ولوحة مشرف محمية وحساب التكلفة الفعلية.
- فتح المحاكاة للجمهور على نطاق واسع.
