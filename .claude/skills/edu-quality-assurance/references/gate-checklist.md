# Educational Quality Gate checklist

| # | Check | Pass when |
|---|---|---|
| 1 | Educational accuracy | Every factual statement on screen matches the blueprint's verified content and sources; no new unsourced claims; numbers and formulas recomputed and correct |
| 2 | Explanation clarity | Language fits the learner level; terms defined before use; one main idea per screen; no ambiguous wording |
| 3 | Content completeness | Every Essential item in the blueprint appears; nothing essential is hidden behind optional "learn more" |
| 4 | Prioritization | Essential content is visually and sequentially prominent; supplementary content does not crowd it |
| 5 | Learning sequence | Order matches the blueprint; prerequisites come first; no forward references without explanation |
| 6 | Interaction suitability | Each interaction matches the concept type, works as designed, and has a non-drag alternative |
| 7 | Feedback quality | Feedback explains why; incorrect options address the targeted misconception |
| 8 | Objective alignment | Each objective has teaching, practice and a check; no orphan activities |
| 9 | Accessibility and language | RTL/LTR correct for the content; terminology consistent; alt text for informative images |
| 10 | Claims about effectiveness | No statement that the app is proven to improve learning; evidence-informed principles named where claimed |

Severity: blocker (wrong fact, missing essential content, broken key interaction), major (confusing sequence, weak feedback, misalignment), minor (wording, consistency).
