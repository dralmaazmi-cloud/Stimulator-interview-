# Screen-by-screen blueprint template

One block per screen. Keep content final-draft quality so it can be reviewed for accuracy.

```
### Screen <module>.<n>: <short name>
Objective(s): <IDs>
Purpose: <what the learner should understand or do after this screen>
Content: <exact text or bullet content; source IDs for factual claims>
Visual / media: <diagram, image, graph; what must be labeled; accuracy reviewer if needed>
Interaction: <type> - <exactly what the learner does>
Feedback: <correct> / <each incorrect option and the misconception it addresses>
Data needed: <inputs, formulas, item bank IDs, assets>
Navigation: <next / branch conditions / skip rules>
Success criterion: <observable signal that the screen worked, e.g. correct on first or second try>
Accessibility and RTL/LTR notes: <alternatives, text direction, numerals>
```

End the blueprint with:
- Retention plan (what is reviewed, when).
- Assessment map (objective to practice and check items).
- Open questions and items needing expert review.
