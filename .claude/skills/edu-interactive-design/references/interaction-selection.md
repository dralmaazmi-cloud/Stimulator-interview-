# Interaction selection guide

| Concept type | First choice | Alternatives | Avoid |
|---|---|---|---|
| Fact or term to recall | Flashcards with spaced review | Quick recall quiz; matching | Long reading with no recall |
| Concept or category | Sort or classify exercise with feedback | Examples vs non-examples quiz | Definitions only |
| Procedure | Step-through worked example, then faded practice | Interactive checklist; guided simulation | Video only, no practice |
| Relationship between quantities | Manipulable simulation (sliders, live graph and numbers) | Interactive comparison of scenarios | Static formula only |
| Spatial or structural (anatomy, devices) | Annotated diagram with tap hotspots and layer or plane toggles | Label-the-image quiz; progressive reveal | Unlabeled images; hover-only labels |
| Process over time | Animation with pause and step controls | Sequenced cards; ordering exercise | Auto-playing animation with no control |
| Judgment or decision | Case-based scenario with decision points and consequences | Decision tree; situational judgement items | Recall questions about judgment |
| Comparison of confusable items | Interactive comparison table or side-by-side toggle | Spot-the-difference quiz | Separate pages for each item |
| Mixed review | Interleaved quiz drawing from all modules | Adaptive exercise set | Blocked practice only |

## Retention mechanisms
Module-end retrieval check; resurfacing missed items later; cumulative review screen; spaced review notifications only with user consent.

## Phone constraints
Tap, not hover; large targets; one interaction per screen; short text near the visual; drag interactions need a tap alternative.
