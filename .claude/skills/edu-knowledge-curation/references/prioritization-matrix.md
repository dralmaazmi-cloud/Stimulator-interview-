# Prioritization matrix

Score each candidate item 0 to 2 on each criterion. Total guides the class; judgment decides.

| Criterion | 0 | 1 | 2 |
|---|---|---|---|
| Objective relevance | Not needed for any objective | Helps an objective | Required for an objective |
| Dependency | Nothing builds on it | Some later content uses it | Prerequisite for essential content |
| Consequence of error | Harmless | Leads to wrong answers | Leads to real-world harm or major misconception |
| Frequency of use | Rare edge case | Sometimes used | Used constantly in the domain |
| Learner readiness | Far beyond current level | Stretch but reachable | Fits current level |

Guide: 8 to 10 Essential; 5 to 7 Supporting; 3 to 4 Optional; 0 to 2 Exclude. Override the guide with a stated reason (for example a rare but safety-critical item stays Essential).
