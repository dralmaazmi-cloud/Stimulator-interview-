# ai-dev-team protected paths for THIS project.

# Team subagents are blocked (at tool level) from writing any file that
# matches a glob below. Use it for approved features, approved designs,
# question banks, answer keys and scoring algorithms.
#
# Syntax: one glob per line, relative to the repository root.
#   **  matches across folders, *  matches inside one folder.
#   A pattern without "/" matches the file name anywhere.
#
# Changing a protected file requires your explicit approval; the
# orchestrator (main session) then makes or applies the change itself.
#
# ---------------------------------------------------------------------------
# Leadership Interview Coach (application lives in work/)
#
# Already protected by the team policy (policy.json), not repeated here:
#   .env, .env.*, *.pem, *.key, vercel.json (any folder), .vercel/**,
#   .claude/**, CLAUDE.md, .mcp.json, .github/**, .git/**
#
# How an authorized change works:
#   1. The user approves a specific change to a specific protected file.
#   2. On a development branch, the orchestrator either makes that change
#      itself, or comments out the matching line below in its own commit so
#      the assigned agent can work, then restores the line afterwards.
#   3. The commit message names the approval. Never unlock on main.
