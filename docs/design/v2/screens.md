# V2 Screen Specs

Conventions: widths 375/390/430; RTL top-to-bottom reading order; "start" = right edge in RTL. Tokens are from `design-system.md` (DS). Gutter = 16px. "Hooks" are the V1 classes/ids/text that the approved harness/tests use and must remain on the same kind of element and visible. All screens: tab roots show header with title only; inner pages show `#back-button`. Page content bottom padding = `nav-h + safe-area + 24px` (except question focus, where nav is hidden by contract).

Global shell (every screen except home): header 52px (+safe top) with `#back-button` (start), `#route-title` (center), spacer (end). Under the header a page head (NEW compact style for `.page-head`): eyebrow 13/700 gold-text, `h1` 28/700, optional 15/muted description max 2 lines. Where `#route-title` equals the `h1` text, `#route-title` keeps its text but is styled 15/700 `--muted` so the large `h1` carries the hierarchy.
