## 1. Learner profile and assumptions
Adult Arabic-speaking professional (manager or aspiring leader) preparing for a competency-based leadership interview; phone-first (iPhone viewport, RTL), sessions of 5-15 minutes, mixed experience with interviews; no prior knowledge of STAR-L/SEAL. [Assumption (Estimated): the brief does not give age, sector or time before the interview; if the interview is within days, the express path in S1 matters most.]

## 4. Sequence and path
Recommended path (shown in S1): U1 (understand) -> U2 (answer building, includes A1-A3) -> U3 (competencies, existing) -> U5 (readiness, includes A4) -> simulation. U4 (mission command) is flagged "تعمّق" and can be deferred until after the first simulation [REF part 4: not asked directly]. A5 flashcards run in parallel, short and daily. Order within U2 follows worked-example-before-practice: decision rule -> explain -> see worked example -> do (sort / missing) -> discriminate (chooser) -> detail.

## 5. Simplified explanations and mnemonics [NEW, consistent with R]
Canonical UI labels (use these everywhere; keep reference long labels as sub-text):
- STAR-L: الموقف (S) · المهمة (T) · الإجراء (A) · النتيجة (R) · التعلّم (L).
- SEAL: فهم الوضع (S) · التقييم (E) · الإجراء (A) · الأثر القيادي (L).

Decision rule (one line): "هل يطلب السؤال قصة حدثت لك؟ STAR-L. هل يضعك في موقف افتراضي ويسألك ماذا ستفعل؟ SEAL."
Mnemonic STAR-L: "موقف، مهمة، إجراء، نتيجة، تعلّم: أنا فعلت، فتغيّر شيء، فتعلّمت." The core is "أنا فعلت" [REF 2.3, 2.4].
Mnemonic SEAL: "افهم، قيّم، تصرّف، أثّر." Evaluation is the heart of a scenario [REF 2.2].
Analogy for Situation vs Task [NEW]: "الموقف هو المشهد، والمهمة هي دورك أنت في المشهد."
Analogy for Result vs Learning [NEW]: "النتيجة ما تغيّر في العمل، والتعلّم ما تغيّر فيك."

### A1. ورشة STAR-L (sort + missing element)
Where: U2 section 6; also reachable from S5, S8 and S1 express card.
Data (derived, not rewritten): behavioural questions with `sample_answer_star_l` having non-empty situation/task/action/result/learning (46 candidates), `question.display_question`. SEAL variant uses `sample_answer_seal` (16+6 = 22 candidates) with 4 elements. Excluded: X1, X2.
Mode 1 "رتّب العناصر":
- Header [NEW]: ضع كل فقرة في العنصر المناسب.
- UI: the question is shown; below, 5 shuffled text cards (the learner's job is to match, so order is randomized); 5 labeled slots (الموقف، المهمة، الإجراء، النتيجة، التعلّم) with the one-line prompt from `modelElements`. Tap a card, then tap a slot (or use a select inside each card). Tap a placed card to return it. Button: تحقّق (enabled when all placed).

## 9. Retention and assessment plan
- Spacing: A5 boxes (1 / 3 / 7 days) [EST]; A2 and A1 are re-offered via S1 express card when last played > 3 days ago.
- Interleaving: A2 mixes the two frameworks; A1 alternates behavioural and scenario in "mixed" mode (default after mastery).
- Retrieval before reveal: existing answer gate (kept), A5, A1 missing-element.
- Mastery signals (all informal): A1 sort 3 clean runs; A1 missing 5 of 6; A2 7/8 twice; U1 and U2 mini-checks passed; A5 >= 80% of the 35 cards in box 3 [EST].
- On failure: hint -> explanation -> worked example (A3) -> retry. No lockout; learners may continue anywhere.
- None of these are tests of readiness. Do not display percentages that imply prediction of the real interview. Label: تمرين للتعلّم، وليس تقييمًا.
- Effectiveness for these learners is unproven; add anonymous local counters (completion, retries) only if the owner approves; no data leaves the device in this design.
